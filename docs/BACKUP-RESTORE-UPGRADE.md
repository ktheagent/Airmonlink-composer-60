# Backup, Restore, and Upgrade Guide

## Backup

1. Close or save the active score.
2. Copy all `.airscore` projects to a separate protected location.
3. Preserve exported MusicXML/MXL, MIDI, PDF, PNG, templates, and organization
   assets that are not reproducible.
4. Verify at least one backed-up project opens on a second location or test copy.

## Restore

1. Install or start a compatible Airmonlink Composer build.
2. Copy the project files into a writable project folder.
3. Open each restored `.airscore` file and verify title, parts, measures,
   lyrics, Staff notation, and Tonic Sol-fa.
4. Re-export a representative PDF or MusicXML file.

## Upgrade

1. Back up projects and exports.
2. Record the installed version.
3. Install the new Setup build without deleting user project folders.
4. Confirm the new visible version and build.
5. Open, edit, save, reopen, play, and export a representative project.
6. Verify printer, MIDI, audio, and file associations.
7. Retain the previous installer until acceptance is complete.

Upgrade behavior for this modified local checkpoint remains pending until both
the new Windows artifact and a supported prior installer are available.
