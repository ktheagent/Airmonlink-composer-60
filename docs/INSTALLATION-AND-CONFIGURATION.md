# Installation and Configuration Guide

## Setup installation

1. Verify the SHA-256 checksum supplied with the release.
2. Run `Airmonlink-Composer-1.3.0-Build50-Setup.exe`.
3. Choose the installation directory when prompted.
4. Start Airmonlink Composer and confirm **1.3.0 · Build 50** is visible.
5. Create a test score, save it, reopen it, and export a PDF before production use.

## Portable edition

Place `Airmonlink-Composer-1.3.0-Build50-Portable.exe` in a writable folder and
run it directly. Keep project files and backups outside temporary directories.

## Initial configuration

- Confirm audio output and playback volume.
- Select the intended MIDI input/output devices.
- Configure page size, margins, and printer.
- Choose the desired Staff/Tonic Sol-fa display preferences.
- Confirm the default project and export folders are writable.

Unsigned builds may trigger Windows reputation warnings. Verify the checksum and
publisher information before proceeding.
