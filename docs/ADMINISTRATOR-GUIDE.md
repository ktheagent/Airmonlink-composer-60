# Administrator Guide

Airmonlink Composer is a local desktop application. Administrators should:

- distribute only checksum-verified Setup or Portable artifacts;
- preserve `.airscore` project files during workstation migration;
- restrict write access to installation directories;
- permit user write access only to approved project, export, and recovery paths;
- validate printer, MIDI, and audio drivers on managed Windows images;
- record the installed version and build number;
- retain release checksums, workflow verification JSON, and smoke-test evidence;
- test upgrades on a representative workstation before broad deployment.

The application does not require a server-side account or payment service in
this checkpoint. Organization-specific endpoint protection, software
distribution, backup, retention, and signing policies remain administrator
responsibilities.
